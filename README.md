# Crypto Market Intelligence Dashboard

Streamlit cryptocurrency market-intelligence dashboard using live market data.

## Prototype v1
- Live crypto market data
- Single/multiple coin selection
- KPI cards
- Market movers
- 24-hour movement
- Historical price trend
- Historical price performance
- Market insights
- Plotly charts
- API/network error handling

AI is intentionally excluded from Prototype v1 and will be developed separately.

## Local run
```bash
pip install -r requirements.txt
streamlit run appv2.py
```

Never commit real API keys.
